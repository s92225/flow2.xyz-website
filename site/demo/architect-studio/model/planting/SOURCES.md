# Planting and hillside materials

- **[Tree Small 02](https://polyhaven.com/a/tree_small_02)** — Rico Cilliers, Poly Haven, [CC0](https://polyhaven.com/license). The tree structure was simplified from the original glTF. Leaf cluster positions were sampled from the source crown, and four small branch sprays were made from its leaf albedo and alpha. All trees use actual 3D orientations, not camera-facing photographs. See `tools/bake-trees.py` in the local preview project for the offline processing.
- **[Aerial Grass Rock](https://polyhaven.com/a/aerial_grass_rock)** — Rob Tuytel, Poly Haven, [CC0](https://polyhaven.com/license). The colour and OpenGL normal maps were downsampled to local WebP textures. The grass tones have been adjusted for this planting concept.

These are visual assets for a design study. The species, planting locations, hillside and outward views are not representations of surveyed conditions at Mount Nicholson. No imagery from a Poly Haven preview page is used as a web model asset.
